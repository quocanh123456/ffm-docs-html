02

Cài đặt

BA, Designer, dev đều dùng Claude Code: cài bằng prompt bên dưới; người chỉ cần xem thì không cần cài

Cài bằng prompt dán vào Claude Code

Mở Claude Code trên máy mình, dán nguyên đoạn dưới đây rồi gửi. Claude Code tự cài và kiểm tra. Máy phải đã đăng nhập GitHub (gh auth status báo đã đăng nhập, hoặc đã có khoá SSH) bằng tài khoản có quyền đọc repo private pancake-vn/ffm-docs-html.

Cài skill thiết kế ffm-design của FFM cho máy này. Làm lần lượt, báo kết quả từng bước:
1. Kiểm tra máy đã đăng nhập GitHub (gh auth status, hoặc đã có khoá SSH). Chưa đăng nhập thì dừng lại và hướng dẫn tôi đăng nhập, không tự nhập token hay mật khẩu.
2. Tìm trên máy bản clone sẵn có của repo pancake-vn/ffm-docs-html. Có thì chạy git pull trong bản đó; nếu bản đó đang có file sửa dở hoặc đang ở nhánh khác main thì báo tôi trước khi pull. Chưa có thì chạy lệnh clone repo vào ~/.agents/ffm-docs-html (ưu tiên gh repo clone pancake-vn/ffm-docs-html). Nếu lệnh clone báo không có quyền đọc repo thì dừng lại và nói rõ để tôi xin quyền.
3. Tạo thư mục ~/.claude/skills nếu chưa có, rồi tạo liên kết ~/.claude/skills/ffm-design trỏ tới thư mục skills/ffm-design trong bản clone ở bước 2. Nếu ~/.claude/skills/ffm-design đã có từ trước (thư mục thật, liên kết trỏ chỗ khác, hoặc liên kết hỏng) thì báo nó đang trỏ tới đâu và hỏi tôi trước khi thay hoặc xoá.
4. Kiểm tra: báo đường dẫn thật mà ~/.claude/skills/ffm-design trỏ tới, đọc được SKILL.md, báo tên skill và phiên bản mới nhất trong CHANGELOG.md.
5. Kiểm tra Claude Code đã có Figma MCP và 2 skill figma-use, figma-generate-design chưa. Thiếu thứ nào thì liệt kê ra.
Cuối cùng nhắc tôi mở session Claude Code mới để skill có trong danh sách.

Khi Ming báo có bản mới, dán prompt:

Cập nhật skill ffm-design: chạy git pull trong bản clone ffm-docs-html mà ~/.claude/skills/ffm-design trỏ tới (bản clone có file sửa dở hoặc đang ở nhánh khác main thì báo tôi trước), rồi báo phiên bản mới nhất và các thay đổi trong CHANGELOG.md của skill.

Hoặc tự chạy lệnh (cùng kết quả với prompt ở trên):

# cài 1 lần (máy đã đăng nhập gh)
gh repo clone pancake-vn/ffm-docs-html ~/.agents/ffm-docs-html
mkdir -p ~/.claude/skills
ln -s ~/.agents/ffm-docs-html/skills/ffm-design ~/.claude/skills/ffm-design

# khi Ming báo có bản mới
git -C ~/.agents/ffm-docs-html pull

Máy đã có sẵn bản clone ffm-docs-html thì dùng bản đó, đổi đường dẫn trong lệnh. ~/.claude/skills/ffm-design đã có từ trước (cài theo README cũ, hoặc liên kết cũ) thì xoá trước khi tạo liên kết, nếu không liên kết bị tạo lồng vào bên trong. Mở session Claude Code mới sau khi cài.

Cần có thêm

  • Figma MCP trong Claude Code của từng người, cùng 2 skill Figma figma-use và figma-generate-design mà bước 0 của quy trình vẽ kiểm tra. Mobbin là tuỳ chọn.
  • Quyền Figma theo vai: BA xem Design System, sửa Planning_FFM và Visual_Design_FFM (bước "Publish" ghi vào file này) · Designer sửa Master_Data_FFM, Visual_Design_FFM và Design System, xem Planning_FFM · Dev xem Master_Data_FFM và Visual_Design_FFM.
  • Trong file đang vẽ: bật library Design System_FFM (Assets → Libraries), nếu không thì AI không chèn được component theo key.
!

Ai dùng claude.ai (không phải Claude Code) thì nén thư mục skills/ffm-design thành file zip có thư mục gốc tên ffm-design, rồi tải lên ở Customize → Skills. Có bản mới thì xoá bản cũ rồi tải lại.

Người chỉ cần xem (vận hành, GIP): không cài skill; xem trang team có nhúng iframe Figma (cần quyền xem file Figma).
